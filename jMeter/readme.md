# Тестирование системы

## Описание проекта

Данный проект предназначен для тестирования производительности и нагрузки приложения с использованием JMeter. Цель тестирования заключается в проверке стабильности и масштабируемости сервиса в условиях высоких нагрузок.

---

## Требования

Для запуска тестов необходимы следующие компоненты:

- **JMeter** — инструмент нагрузочного тестирования.
- **Tcl/Tk** — интерпретатор скриптов Tcl.
- **GRPC Plugin for JMeter** — расширение для поддержки gRPC запросов.

---

## Установка зависимостей

### Шаг 1: Установите JMeter

Установите последнюю версию Apache JMeter.

### Шаг 2: Добавьте GRPC-плагин

Следуйте инструкциям по установке плагина gRPC Request из репозитория https://github.com/zalopay-oss/jmeter-grpc-request или менеджера плагинов https://jmeter-plugins.org/install/Install/



### Шаг 3: Настройте пути файлой `.proto` и `payload`

Проверьте jmx файлы тестов, что пути до `.proto` и `payload` верные

```

├── result/                        # Папка с результатами тестов _создается автоматически_
└── ...

```

# Как запустить тесты?

### README: `run‑jmeter‑bg.tcl`

## Назначение

Скрипт для **удобного запуска JMeter‑тестов** (`.jmx`‑файлов) из командной строки:
- показывает меню выбора теста;
- запускает выбранный тест **в фоновом режиме**;
- отслеживает выполнение по PID;
- выводит статус во время работы;
- после завершения возвращает в меню.

## Требования

- Tcl 8.5+ (`tclsh`);
- JMeter в директории `./bin/jmeter` (относительно места запуска скрипта);
- права на запись в папку `./result/`.

## Установка

1. Положите скрипт `run-jmeter-bg.tcl` в директорию с вашими `.jmx`‑файлами.
2. Убедитесь, что `bin/jmeter` доступен.
3. Сделайте скрипт исполняемым (если нужно):

   ```bash
   chmod +x run-jmeter-bg.tcl
   ```

## Запуск

### Интерактивный режим (меню)

```bash
tclsh run-jmeter-bg.tcl
```

или (если скрипт исполняемый):

```bash
./run-jmeter-bg.tcl
```

### Запуск конкретного теста по номеру

```bash
tclsh run-jmeter-bg.tcl <номер>
```

Пример:

```bash
./run-jmeter-bg.tcl 2
```

> Номер теста — это позиция в алфавитном списке `.jmx`‑файлов (начиная с 1).

## Выходные данные

Результаты теста сохраняются в:

```
result/<имя_теста>/<гггг-мм-дд-чч-мм>/
├── results.csv        # результаты тестирования
├── log.log          # лог JMeter
└── report/           # HTML‑отчёт
```

## Особенности

- **Фоновый запуск**: скрипт не блокируется, но следит за процессом.
- **Мониторинг по PID**: использует `kill -0 <PID>` для проверки активности.
- **Возврат в меню**: после завершения теста можно запустить другой или выйти.
- **Обработка ошибок**: проверяет существование файлов, корректность ввода, доступность JMeter.
